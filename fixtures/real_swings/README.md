# Real-swing smoke fixtures

Drop your own paired clips here for `python run_all_tests.py --smoke`:

| File | View |
|------|------|
| `face_on.mp4` | Camera facing the golfer |
| `dtl.mp4` | Down-the-line (behind the golfer) |

Videos are gitignored. If these files are missing, the smoke uses the newest `recordings/recording_*_camera1/2.mp4` pair, or downloads the small public GolfDB demo swing (DTL, research/demo use; McNally et al., CVPRW 2019).
